# Strata

Рабочее место для восстановления данных и поиска потерянных криптокошельков на старых дисках.
Rust + GPUI.

## Что умеет

- **Источники:** сырые образы (`.img`, `.dd`, разбитые `.001…`), образы R-Studio (`.rdr`, с `.scn` и без),
  физические диски `\\.\PhysicalDriveN` только на чтение, с обходом битых секторов.
  Два образа одного диска склеиваются: битые сектора одного читаются из другого.
- **Разделы:** MBR/EBR, GPT, поиск потерянных/удалённых разделов по загрузочным секторам.
- **Один проход по диску:** все детекторы работают за одно последовательное чтение
  (ключи WIF/xprv/DER/hex/minikey, seed-фразы, wallet.dat, адреса, e-mail, URL сервисов).
  Прерванное сканирование продолжается с места остановки.
- **Привязка к файлам:** каждая находка показывает файл (живой, удалённый, сирота) и смещение в нём.
- **Балансы:** найденные и выведенные адреса проверяются через Esplora (mempool.space по умолчанию,
  можно указать свой сервер).
- **Несколько дисков в одном деле:** общие ключи/адреса/аккаунты между дисками, файлы, которые
  на одном диске удалены, а на другом целы.
- **Отчёты:** Markdown (русский), HTML, CSV, JSON.

## Сборка

```
cargo build --release -p strata        # GUI
cargo build --release -p strata-cli    # консоль
```

## Консоль

```
strata-cli -c D:\cases\disk1.strata add "F:\images\disk.rdr"
strata-cli -c D:\cases\disk1.strata list
strata-cli -c D:\cases\disk1.strata analyse          # индекс файлов + скан + балансы
strata-cli -c D:\cases\disk1.strata hits --category PrivateKey
strata-cli -c D:\cases\disk1.strata correlate
strata-cli -c D:\cases\disk1.strata balances --endpoint https://my-esplora/api
strata-cli -c D:\cases\disk1.strata report md
```

Улики открываются только на чтение. Ключи и фразы в интерфейсе и отчётах показываются открыто:
не пересылайте отчёты третьим лицам.

## Архитектура

Cargo workspace, каждый crate — отдельный bounded context. Правила: [docs/CODESTYLE.md](docs/CODESTYLE.md).

| crate | назначение |
|---|---|
| kernel | общие типы: диапазоны, время, повреждения, контракт детекторов |
| source | образы, R-Studio, физические диски, склейка образов |
| volume | таблицы разделов, поиск потерянных разделов |
| fs | NTFS, FAT: удалённые и осиротевшие записи, offset → файл |
| identify / carve | тип файла по содержимому, смена расширения, повреждённые файлы, карвинг |
| crypto | ключи, seed-фразы, кошельки, вывод адресов |
| accounts | e-mail, логины, сервисы |
| artifacts / timeline | браузеры, реестр, LNK, Prefetch, корзина, хронология |
| chain | балансы адресов |
| engine | однопроходный сканер |
| case | дело: SQLite, привязка находок, корреляция дисков |
| report | экспорт отчётов |
| workbench | прикладной слой для GUI и CLI |
